# Etchost v0.6.1

## 한국어

- 업데이트 확인 시 새 버전 안내 시트 추가 (릴리스 노트 + 업데이트 방법 + 다운로드 버튼)
- Dock 클릭으로 호스트 관리 창 열기 / 맨 앞으로 가져오기
- 설정에 "앱 실행 시 호스트 관리 열기" 추가 (기본 OFF)
- 메인 창을 닫아도 앱이 종료되지 않고 메뉴바에 상주
- 메뉴 문구 "메인 창" → "호스트 관리"로 변경
- 게시된 릴리스가 없으면 "게시된 릴리스가 없습니다"로 표시

### 설치 방법

1. 아래 `Etchost-v0.6.1.zip`을 받아 압축을 푸세요.
2. `Etchost.app`을 `~/Applications`(또는 `/Applications`)에 옮기세요.
3. 첫 실행은 **우클릭 → 열기**로 실행하세요. (공증 없는 배포라 Gatekeeper 확인용입니다.)

## English

- New version sheet on update check (release notes + how to update + Download button)
- Clicking the Dock icon opens / brings the Host Manager window forward
- New setting: "Open Host Manager on launch" (default OFF)
- Closing the main window no longer quits the app; it stays in the menu bar
- Menu wording changed from "Main Window" to "Host Manager"
- Shows "No published releases yet" when there is nothing to compare against

### Install

1. Download `Etchost-v0.6.1.zip` below and unzip it.
2. Move `Etchost.app` into `~/Applications` (or `/Applications`).
3. On first launch, **right-click → Open**. (This build is not notarized, so Gatekeeper needs a manual approval.)
