# Etchost v0.6.2

## 한국어

### 안정성 (P0)
- 호스트 저장소: 중복 UUID 복구, 손상 파일 격리(quarantine), 저장 실패 시 메모리 롤백 + 오류 노출
- 호스트 지문을 SHA256으로 결정적 계산 — 재시작 후 오판 방지
- 프로필/프래그먼트/툰 저장소: 데이터 디렉터리 부재 시 안전 폴백 (crash 제거)

### 개선 (P1)
- 네트워크 스캔: 취소·진행률 동기화·선택 복원·스크롤 래프
- 에디터: dirty 판정 개선, 저장 메시지 슬롯, 프래그먼트 첫 동기화 오류 수정
- 사이드바: 삭제 확인, 고유 기본 이름, 적용 중 재진입 가드
- 호스트 관리 창: 재오픈 폴백 3단계 + 지연 재시도, 포커스 경합 해소

### 정리 (P2)
- SPM 리소스 경고 제거, 미사용 리소스 삭제
- SettingsView 분리로 앱 진입점 경량화

### 설치 방법

1. 아래 `Etchost-v0.6.2.zip`을 받아 압축을 푸세요.
2. `Etchost.app`을 `~/Applications`(또는 `/Applications`)에 옮기세요.
3. 첫 실행은 **우클릭 → 열기**로 실행하세요. (공증 없는 배포라 Gatekeeper 확인용입니다.)

## English

### Stability (P0)
- Host stores: duplicate-UUID recovery, quarantine for corrupted files, in-memory rollback + error surfacing on save failure
- Deterministic SHA256 host fingerprints — no stale mismatches after restart
- Profile/fragment/tunnel stores: safe fallback when the data directory is missing (no crash)

### Improvements (P1)
- Network scan: cancel, progress sync, selection restore, scroll wrapping
- Editor: better dirty detection, save-message slot, first-fragment-sync fix
- Sidebar: delete confirmation, unique default names, re-entry guard while applying
- Host Manager window: 3-step reopen fallback + delayed retry, focus race resolved

### Cleanup (P2)
- Removed SPM resource warnings and unused resources
- Split out SettingsView for a lighter app entry point

### Install

1. Download `Etchost-v0.6.2.zip` below and unzip it.
2. Move `Etchost.app` into `~/Applications` (or `/Applications`).
3. On first launch, **right-click → Open**. (This build is not notarized, so Gatekeeper needs a manual approval.)
